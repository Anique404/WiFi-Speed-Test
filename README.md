

# 📡 Wi-Fi Speed Tester Web App

A simple and user-friendly web application to test your internet/Wi-Fi speed in real-time. Built with Python and a clean web interface.

## ✨ Features
- **Real-time Speed Testing** – Check your download and upload speed instantly
- **Ping/Latency Measurement** – View your network response time
- **Simple UI** – Easy to use, no installation required
- **Lightweight** – Fast and responsive design
- **Multi-language Support** – Backend in Python, frontend with HTML, CSS, JavaScript

## 🚀 How to Use 
1. Open the website in your browser
2. Click the **"Start Test"** button
3. Wait a few seconds for download & upload speed results
4. View your ping and speed details

## 🛠️ Technologies Used
- **Backend**: Python (Flask/FastAPI)
- **Frontend**: HTML, CSS, JavaScript
- **Others**: PowerShell (for scripts), C (for performance modules)

## ⚙️ Setup & Installation
### 1. Clone the repository
```bash
git clone https://github.com/your-username/wifi-speed-test.git
cd wifi-speed-test
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
python app.py
```

### 4. Open in browser
Go to `http://localhost:5000`
